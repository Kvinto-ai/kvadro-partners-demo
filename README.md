# Квадро Партнёры — интерактивное демо

Внутренняя система управления партнёрским каналом мебельной студии: дизайнеры, архитекторы, строители, прорабы, комплектаторы и декораторы.

## Демо

После включения GitHub Pages приложение доступно по адресу:

**https://kvinto-ai.github.io/kvadro-partners-demo/**

## Что работает интерактивно

- навигация по разделам «Сегодня», «Партнёры», «Объекты», «Аналитика», «Мероприятия» и «Комиссии»;
- поиск и комбинированные фильтры партнёров;
- карточка партнёра с историей контактов, объектами, договорами, комиссиями и мероприятиями;
- канбан объектов, перенос карточек между этапами и табличный вид;
- карточка объекта со сменой этапа;
- добавление партнёра, объекта и контакта;
- выполнение задач;
- переключение периода аналитики;
- просмотр карточек мероприятий;
- смена статусов комиссий;
- сохранение изменений в localStorage и восстановление исходного демо;
- адаптивное меню и интерфейс для телефона.

## Демонстрационные данные

Приложение содержит 20 партнёров, 25 объектов, 12 договоров, 4 мероприятия и 12 комиссий. Сервер и база данных не используются: изменения сохраняются только в браузере пользователя.

## Подключение базы

Для перехода к рабочей версии потребуется создать структуру таблиц в Baserow или PostgreSQL, настроить связи и правила расчёта комиссий, заменить localStorage на API-запросы, добавить авторизацию, роли, журнал изменений и резервное копирование.

## Стек

Статическое приложение на HTML, CSS и JavaScript без внешних библиотек и секретных ключей. Публикация выполняется автоматически через GitHub Actions и GitHub Pages.
